# Veyro — Personal Finance Tracker

**Spend smarter. Stay in control.**

Veyro is a personal finance tracking web application designed to help users manage their daily budgets, record expenses, and monitor their spending habits through a clean, modern dashboard.

## ✨ Features

- **Daily Budget Management** — Set a daily spending limit and track your available balance.
- **Expense Tracking** — Record expenses with an amount, category, and optional note.
- **Spending Overview** — View today's total spending, remaining budget, and budget usage percentage.
- **Budget Alerts** — Receive alerts when spending reaches 80% of the budget or exceeds the limit.
- **Expense History** — Review previously recorded expenses and delete entries when needed.
- **Persistent Storage** — Save budgets and expenses in the browser using LocalStorage.
- **Responsive Interface** — A dark-themed dashboard with charcoal backgrounds and lime-green accents.

## 💾 Data Storage

Veyro uses browser LocalStorage to retain budgets and expense records between visits.

Data is stored locally in the browser and is not automatically synchronized across devices or browsers. Clearing the site's browser storage may erase saved records.

## 🎯 Project Goals

This project was built to practise front-end web development, JavaScript event handling, form validation, DOM manipulation, data persistence, and responsive user interface design.
